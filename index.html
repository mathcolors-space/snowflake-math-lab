Δημιούργησε το μοτίβο σου

Μαθηματικός κανόνας
360° ÷ 6 = 60°
Κάθε επόμενος βραχίονας στρέφεται κατά 60°.

Παρατήρησε τη χιονονιφάδα

Άλλαξε τις παραμέτρους. Τι παραμένει ίδιο και τι αλλάζει;

Observe — Παρατήρησε

Πρώτα σκέψου, μετά πάτησε «Δείξε μου».

1. Από ποια επαναλαμβανόμενα μέρη αποτελείται η χιονονιφάδα;

2. Αν γνωρίζεις πώς σχεδιάζεται ένας βραχίονας, πώς δημιουργείς όλη τη χιονονιφάδα;

3. Τι πρέπει να αλλάζει μετά από κάθε βραχίονα ώστε να μην πέφτουν όλοι στην ίδια θέση;

4. Ποια είναι η γωνία περιστροφής ανάμεσα σε δύο διαδοχικούς βραχίονες;

Διάλεξε μία απάντηση:

Build — Κατασκεύασε έναν βραχίονα

Πρόβλεψε τι θα σχεδιαστεί πριν προχωρήσεις στο επόμενο βήμα.

Repeat — Από έναν βραχίονα στη χιονονιφάδα

Μπορείς να φτιάξεις έξι ίδιους βραχίονες χωρίς να αντιγράψεις έξι φορές τις ίδιες εντολές;

Συμπλήρωσε τα δύο κενά και πάτησε «Εκτέλεση».
επανάλαβε φορές {
　// ο κώδικας του Build: σχεδίαση ενός βραχίονα και επιστροφή στο κέντρο
　στρίψε δεξιά °
}
Μια πλήρης περιστροφή είναι 360°. Σε πόσα ίσα μέρη τη χωρίζουμε;

Μπράβο! Με μία επανάληψη κατασκεύασες έξι ίδιους βραχίονες. Στο επόμενο στάδιο θα αλλάξουμε το μέγεθος με μεταβλητή.

Size — Αλλάζω το μέγεθος με μεταβλητή

Ο κώδικας της χιονονιφάδας παραμένει ίδιος. Τι θα αλλάξει αν χρησιμοποιήσουμε μία μεταβλητή;

Πρόβλεψη: Αν διπλασιάσουμε την τιμή της μεταβλητής size, τι θα συμβεί;

Σωστά! Πολλαπλασιάζουμε τα μήκη με τη μεταβλητή size. Οι γωνίες 45° και 60° δεν αλλάζουν.

Δοκίμασε size = 1 και μετά size = 2. Τι παραμένει ίδιο;

Position — Συντεταγμένες x, y

Πρώτα επιλέγεις εσύ τη θέση. Μετά ανακαλύπτεις πώς θα γίνεται τυχαία.

Γνώρισε τη σκηνή του Scratch

Η σκηνή έχει πλάτος 480 και ύψος 360 μονάδες. Το κέντρο είναι (0, 0). Το x αυξάνεται προς τα δεξιά και το y προς τα πάνω.

Ποια είναι τα όρια των συντεταγμένων στη σκηνή;

Για τις τυχαίες θέσεις θα χρησιμοποιήσουμε μικρότερα όρια (x: −200 έως 200, y: −140 έως 140), ώστε να αφήνουμε χώρο γύρω από τη χιονονιφάδα. Αν είναι μεγάλη, μπορεί να χρειάζεται ακόμη μεγαλύτερο περιθώριο.

Πρόβλεψη: Αν αυξήσω το x, προς τα πού μετακινείται η χιονονιφάδα;

Μετακίνησε τη χιονονιφάδα και παρατήρησε τις συντεταγμένες του κέντρου της.

Πώς μπορεί να εμφανίζεται η χιονονιφάδα κάθε φορά σε διαφορετική θέση χωρίς να γράφουμε νέες τιμές;

Μπορεί να εμφανιστεί στη θέση x = 250;

Snowfall — Προγραμμάτισε τη χιονόπτωση

Πρώτα προβλέπεις, μετά συμπληρώνεις τον αλγόριθμο, εντοπίζεις το σφάλμα και στο τέλος εκτελείς.

1. Πώς θα κρατήσουμε ολόκληρη τη χιονονιφάδα μέσα στη σκηνή;

Η σκηνή του Scratch εκτείνεται από x = −240 έως +240 και από y = −180 έως +180. Η χιονονιφάδα έχει και δικό της μέγεθος!

1. Ποια επανάληψη περιλαμβάνει συνθήκη τερματισμού;

2. Συμπλήρωσε τις δύο τιμές της μεταβλητής ελέγχου.

όταν γίνει κλικ στην πράσινη σημαία όρισε stop σε [ ? ] σβήσε όλα επανάλαβε ώσπου <stop = [ ? ]> πήγαινε σε τυχαία θέση όρισε size σε τυχαία τιμή σχεδίασε χιονονιφάδα περίμενε 0.5 δευτερόλεπτα

3. Αποσφαλμάτωση: πατάμε «Σταμάτα», αλλά συνεχίζει να χιονίζει. Τι λείπει;

Ο αλγόριθμός σου είναι έτοιμος!

Το κουμπί «Σταμάτα» μεταδίδει μήνυμα. Ένα δεύτερο σενάριο ορίζει stop = 1, οπότε η επανάληψη τερματίζεται στον επόμενο έλεγχο.

Χιονονιφάδες: 0

Πρόκληση: Αν ξαναπατήσεις την πράσινη σημαία, ποια πρέπει να είναι η αρχική τιμή του stop;

COLOR — Μία εντολή, δύο αποτελέσματα!

Επίλεξε το αποτέλεσμα, πρόβλεψε πού θα μπει η εντολή και έλεγξε την απάντησή σου. Έπειτα εκτέλεσε το πρόγραμμα.

1. Πού θα τοποθετήσεις την εντολή αλλαγής χρώματος;

2. Τώρα άλλαξε στόχο!
